# Mission Prospection Textile Europe — SourcingLabUSA
**Date : 2026-10-25 | Statut : Batch 1 livré — vérification en cours**

## 1. Objectif
Identifier des clients potentiels européens (marques et importateurs textile/mode) qui pourraient travailler avec SourcingLabUSA pour du sourcing de production (Asie : Vietnam, Bangladesh, Inde, Chine) ou pour l'optimisation de leur supply chain.

## 2. Contexte marché (2026)
- Les marques européennes **diversifient activement** leur sourcing hors Chine vers Vietnam, Bangladesh, Inde (McKinsey State of Fashion 2025).
- L'accord UE-Vietnam réduit progressivement les tarifs (élimination totale prévue 2027) → fenêtre commerciale pour les marques qui migrent vers le Vietnam.
- Les exportations Bangladesh→UE reculent (-11,7%) → opportunité de capter les marques qui réévaluent leurs fournisseurs.

## 3. ICP (profil client idéal)
- **Taille** : marques DTC/e-commerce de taille moyenne (10-200 salariés) OU importateurs/grossistes privés.
- **Signaux** : production externalisée, croissance DTC, expansion internationale, pressions tarifaires/CGE (due diligence UE sur les chaînes d'approvisionnement).
- **Décideurs cibles** : Head of Sourcing / Supply Chain Manager / Founder-CEO (pour les petites structures).

## 4. Différence clé vs mission USA
| | USA | Europe |
|---|---|---|
| Preuve imports | ImportYeti (données douanières US publiques) | **Pas d'équivalent public européen** → preuves via presse, sites, LinkedIn, registres |
| Vérification | Score /100 avec statuts Vérifié/Déclaré | Même framework, statut "Déclaré" tant que vérification non faite |
| Sources | ImportYeti + sites | Good On You, Euratex, presse mode, LinkedIn, registres nationaux |
